# WeLife — Requirements Traceability Matrix

Maps every requirement in the specification (§ = section) to modules, screens, data entities,
milestone and tests. **Status** is updated at each milestone review:
`Done` = implemented and verified by the listed tests · `Partial` = foundation only · `Planned`.

Screen numbers refer to spec §3 (S1 Start … S21 Settings).
